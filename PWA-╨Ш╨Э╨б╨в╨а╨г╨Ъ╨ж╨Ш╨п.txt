AETHER WEATHER — PWA

Файлы PWA уже добавлены:
- manifest.json — название, режим приложения и иконки;
- service-worker.js — кэширование оболочки и офлайн-открытие;
- icons/icon-192.png — иконка 192x192;
- icons/icon-512.png — иконка 512x512;
- icons/icon-maskable-512.png — адаптивная Android-иконка 512x512.

КАК ПРОВЕРИТЬ
1. Загрузи содержимое папки weather на хостинг (например, Vercel).
2. Сайт должен открываться по HTTPS. На localhost тоже можно тестировать.
3. Открой сайт в Chrome/Edge. Через несколько секунд появится окно установки.
4. Android: кнопка вызывает системное окно установки, если браузер разрешил beforeinstallprompt.
5. iPhone/iPad: открой сайт в Safari -> Поделиться -> На экран Домой -> Добавить. iOS не позволяет сайту вызвать системную установку автоматически.
6. Desktop: используй кнопку установки или меню браузера -> Установить приложение.

ВАЖНО
- Нельзя программно гарантировать установку иконки на рабочий стол на всех устройствах: последнее подтверждение всегда контролирует ОС/браузер.
- Для проверки повторного показа окна очисти localStorage сайта (ключ aether-install-dismissed) или используй приватное окно.
- Прогноз погоды через API требует интернета. Офлайн будет доступна оболочка приложения, а не новые погодные данные.
